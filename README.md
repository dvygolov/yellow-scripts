46 скриптов для лендингов: формы, игры, виджеты, медиа и обработка заявок. На странице скрипта есть работающий пример, код подключения, зависимости и ссылки на исходники. Для PHP нужен сервер; Cloudflare Pages его не исполняет.

## Подключение

Выберите пример и скачайте ZIP. В нём находятся HTML, CSS, JS, изображения, зависимости и инструкция. Четыре формы доступны отдельными комплектами. Примеры запускаются через локальный HTTP-сервер; пути внутри архивов относительные.

`demo-common.js` блокирует отправку форм. Для рабочего лендинга подключите свой обработчик и уберите этот перехват. PHP-обработчики по умолчанию работают в режиме `dry-run`, а новые комментарии сохраняются только в браузере посетителя. Значения Social Proof заданы для примера.

## Исходники

Рулетка: [YWB.Roulette.JS](https://github.com/dvygolov/YWB.Roulette.JS). Остальные источники указаны в `catalog.json` и на страницах каталога.

Авторы библиотек сохраняют свои права. Лицензии jQuery, Inputmask, Slick и Lucide находятся в `vendor/licenses`. Фотографии для эффектов: Unsplash, `photo-1464822759023-fed622ff2c3b` и `photo-1501785888041-af3ef285b470`.
