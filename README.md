# Yellow Scripts

Каталог скриптов для лендингов от Жёлтого Веба.

Сайт: https://yellow-scripts.pages.dev

46 разделов: формы, игры, визуальные эффекты, заявки и домонетизация. Каждая страница содержит описание, подключение и ссылки на оригинальные источники. Примеры запускаются отдельно от каталога.

## Использование

Откройте сайт, выберите скрипт и прочитайте раздел подключения. В demos лежат самодостаточные HTML-примеры вместе с JS, CSS и изображениями; общие стили и библиотеки находятся в корне и vendor. На рабочий лендинг не переносите demo-common.js: он отключает отправку форм. Исходные архивные PHP-файлы в sources предоставлены как текст и отмечены предупреждениями.

## Рулетка

Новый модуль: demos/roulette/ywbroulette.js, CSS и prizewheel.png. API: initRoulette({ selectors: { roulette: '#roulette', form: '#order' }, texts: { title: 'Откройте скидку' } }). Контейнер игры и форма должны быть отдельными элементами. Доступны duration, stopAngle, image, onResult, onComplete; экземпляр содержит spin(), destroy(), state.

## Локальный просмотр

Запустите любой статический HTTP-сервер в корне репозитория, например npx serve . Абсолютные пути рассчитаны на корень домена. PHP здесь не исполняется.

## Источники и права

Авторы исходных библиотек сохраняют свои права. Ссылки на исходники есть в catalog.json и на страницах скриптов. Иллюстрация колеса: CPARIP. jQuery, Inputmask, Slick, Lucide распространяются на условиях их лицензий в vendor. Фотографии для эффектов: Unsplash, photo-1464822759023-fed622ff2c3b и photo-1501785888041-af3ef285b470.

В демо нет отправки лидов или реальной аналитики. События выводятся локально. Данные посетителей в архивных Social Proof-виджетах являются заданными примерами.
