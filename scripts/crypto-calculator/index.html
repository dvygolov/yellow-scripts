Подключение

  1. Перенесите HTML калькулятора, его CSS и функцию showresult() из index.html.
  2. Поле #screenInput содержит исходную сумму. Коэффициент n2 в функции задаёт множитель; #j-res1, #j-res2, #j-res3 показывают результаты за 1, 7 и 30 дней.
