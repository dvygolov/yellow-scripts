Форма MoneyCrafter

Встраиваемая форма с заголовком, цветом и sub1 в URL.

PHP + HTML; возможен JS-порт1.0.0JS-адаптация

Пример

JS-адаптация

Отправка форм в примере отключена.

Подключение

  1. Подключите moneycrafter.js перед закрывающим </body>. Создайте пустой контейнер для формы.
  2. Вызовите initMoneyCrafter({ selector: "#moneycrafter", title: "Оставьте заявку", color: "#218575", action: "/order.php", sub1: "..." }).
  3. Укажите существующий серверный обработчик в action. Сам скрипт не отправляет письма и не подключает API партнёрки.
  4. Для iframe используйте embed.html?color=218575&h1=Оставьте%20заявку&sub1=example&action=/order.php. Обработчик должен находиться на домене встроенной формы; демонстрационный хост отправку блокирует.

Что учесть

Адаптация найденной PHP/iframe-формы для статического сайта. Исходный order.php в архиве отсутствует.
