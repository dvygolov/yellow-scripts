Подключение

  1. Откройте исходник или рабочий HTML примера по ссылке ниже.
  2. Перенесите HTML, подключение CSS и JS в лендинг. Сохраните пути к ассетам, настройте тексты и параметры под свою страницу.
  3. Проверьте выбранный сценарий на мобильном и компьютере до установки на рабочий трафик.

Что учесть

Popunder под активным окном нельзя гарантировать: браузеры ограничивают управление фокусом. Пример открывается только по явному клику.
