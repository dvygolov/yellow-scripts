Подключение

  1. Подключите ywbconfetti.js с атрибутом data-auto="false" и создайте const confetti = new Confetti(). Без этого атрибута библиотека запускает эффект при загрузке.
  2. В обработчике кнопки вызовите confetti.start(4000). Длительность задаётся в миллисекундах; повторный вызов запускает эффект заново.
