Подключение

  1. Скопируйте файлы примера в папку лендинга, сохранив относительные пути к CSS и изображениям.
  2. Подключите скрипт и перенесите блок HTML из примера. Названия контейнеров должны совпадать с конфигурацией.
  3. Подставьте свои тексты и адрес обработчика формы. Демонстрационный перехват отправки из demo-common.js на рабочем лендинге не нужен.
