Подключение

  1. При сборке ссылки используйте URL и URLSearchParams. Перенесите только нужные входные параметры через searchParams.set.
  2. Не передавайте персональные данные в URL. Определите приоритет одинаковых параметров; в примере входное значение заменяет имеющееся.
